# 截图目录说明

本目录当前只保留说明文件，没有实验截图。李潇健按 `../操作步骤与截图说明.md` 在当前电脑实际操作并亲自截 PNG，之后在 `../report.md` 第五节引用。姚均和朱彦泽承担答辩主题，不提供虚构的独立机器截图。

```text

02-编译产物.png
03-ELF与符号.png
04-QEMU启动.png
05-复位与预装载.png

07-固件交权至内核.png
08-栈与尾调用.png
09-监视点.png（可选，实际执行后才引用）
```

所有图片均来自本机实际操作人。当前缺少官方 `tools/grade.sh`，不得创建或提交伪造的 `grade_result.png`。
