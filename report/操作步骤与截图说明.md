## 从当前分支复核

在已配置交叉编译工具链与 QEMU 的 WSL 中，从本仓库根目录执行：

```bash
cd code
riscv64-unknown-elf-gcc --version | head -n 1
qemu-system-riscv64 --version | head -n 1
make -B -j2
make qemu
```

内核正常启动后应显示 `memory management: best_fit_pmm_manager` 和 `check_alloc_page() succeeded!`。内核随后进入常驻循环，QEMU 不会自动退出；取得真实终端输出后，按 `Ctrl+A`，松开，再按 `X` 退出。然后运行：

```bash
make grade
```

评分脚本应显示 `check page init: OK`、`check best fit: OK`、`Total Score: 20/20`。`make grade` 会清理构建产物；若之后再运行 `make qemu`，先执行 `make`。最终结果以实际运行的终端画面为准。

现有图 10 没有拍到 `make qemu` 命令及后续两行 `satp` 地址；如果课程要求命令与结果同屏，应由实际操作人补截。截图的操作人和个人贡献由小组按真实情况确认。
